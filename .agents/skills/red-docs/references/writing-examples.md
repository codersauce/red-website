# Writing examples

Use these examples to diagnose a draft's direction. Verify every product fact and shortcut against the current Red revision before reusing it.

## Replace AI positioning with behavior

**Avoid**

> Red provides a seamless, AI-native, context-aware editing experience that empowers developers to stay in flow.

**Prefer**

> Open Red's Agent panel from the editor. Red shows proposed edits where they apply so you can inspect them before accepting them.

The revision names the surface, action, and review behavior. It does not tell the reader how to feel.

## Replace abstract capability claims

**Avoid**

> Leverage Red's powerful language intelligence to streamline your development workflow.

**Prefer**

> Use completion, diagnostics, and navigation from the language server configured for the current file.

The revision replaces three abstractions with concrete product behavior.

## Put the task before background

**Avoid**

> Red offers a flexible and comprehensive configuration system designed to accommodate a wide variety of developer preferences. In order to begin customizing the editor, you will first need to locate your configuration file.

**Prefer**

> Open Red's configuration file, then change only the settings you want to own.

Follow with the verified path and command. Put configuration philosophy on an explanation page if readers need it.

## Keep necessary product terms

**Avoid**

> The smart helper examines your code and intelligently suggests improvements.

**Prefer**

> The Agent panel sends the current editor context to the configured agent and displays its response in Red.

Do not replace exact terms with friendlier but inaccurate synonyms. Verify what context is sent before publishing the sentence.

## Cut an unnecessary section

**Avoid**

```markdown
## Why this matters

This capability is important because it allows developers to work more efficiently.
```

**Prefer**

Delete the section. Let the preceding command and result show its value.

## Report an evidence gap outside the page

**Avoid**

> Press `Space D` to start Delegate Mode.

**Prefer**

Leave the instruction out until the current command or keybinding is verified. Tell the maintainer that the proposed behavior lacks current product evidence.
